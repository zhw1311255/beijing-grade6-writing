# 通用写法手册（语文 / 英语共用）

## 1. 审题四问

1. **写什么**：题眼是哪个词？"温暖""成长""一次""难忘"各自限定了什么。
2. **写多少**：字数 / 句数 / 信息点数。英语题把每个提示问题编号，成稿逐句对照。
3. **写成什么样**：文体、人称、时态、格式（是否要自拟题目、是否要称呼落款）。
4. **不许写什么**：真实校名与师生姓名、消极内容、超纲词、试卷未要求的额外发挥。

审题结果转化为一张"段落 → 内容 → 字数"表，再动笔。

## 2. 语文结构模板（450 字记叙文）

| 段 | 内容 | 建议字数 |
| --- | --- | --- |
| 1 | 开头点题，直接落到那个场景，不绕弯 | 40–50 |
| 2 | 事情起因，交代时间地点人物 | 50–60 |
| 3 | 经过（一）：动作、语言、看到的细节 | 90–110 |
| 4 | 经过（二）：卡点 / 转折，心理与神态，最详部分 | 110–130 |
| 5 | 结果与情感变化，写出"我"前后不一样 | 70–90 |
| 6 | 结尾扣题，一句感悟，不喊口号 | 40–50 |

500 字以上的单元习作：把第 3、4 段各加 30–40 字细节，其余不变。**不要靠加排比句凑字数**。

**想象文**：设定一句话交代清楚 → 奇遇展开（2–3 个具体情节，写清看到什么、做了什么）→ 一个困难与解决 → 回到现实或留一句意味深长的收束。想象要"合理"，即内部规则自洽，不堆砌设定名词。

**读后感 / 观后感**：引（读了什么，一两句）→ 议（最受触动的一点）→ 联（联系自己的一件真事，占一半篇幅）→ 结（收获）。感为主，复述情节不超过全文四分之一。

**活动 / 场面类**：点面结合——先用一句写全场气氛（面），再聚焦一两个人的动作神态（点），最后写自己的感受。

## 3. 细节四件套与情感变化线

每个重点段落至少出现两类细节：

- **动作**：拆成连续小动作（"攥紧""挪了一步""又把手缩回来"），不用概括词"很努力"。
- **语言**：写 1–2 句短对话，符合人物身份，别让小学生说大道理。
- **神态**：写可见的变化（耳根发烫、眼睛亮了一下、低头盯着鞋尖）。
- **心理**：写当时真实的念头与犹豫，不写事后总结式的感悟。

**情感线**：开头一种状态 → 中途受挫或误会 → 转折 → 结尾变化后的状态。北京题常明确要求"如果在事情发展过程中情感有所变化，要把变化写清楚"，成稿必须能画出这条线。

## 4. 语言分级（最重要的质量闸门）

**可用**：六年级课本常见词、常用成语（每篇 2–4 个，用在准确处）、比喻与拟人各 1–2 处、短句与短对话、口语化的生活用语、具体名词（"搪瓷缸""跳绳""粉笔灰"）。

**禁用（成人腔 / 空话 / 网络语 / 超纲）**：

- 成人腔词：岁月静好、氤氲、旖旎、斑驳、镌刻、潸然、婆娑、缱绻、韶华、浮生、惊艳了时光、温柔了岁月、静谧、呢喃、阑珊。
- 口号与套话：不忘初心、砥砺前行、谱写华章、赋能、格局、闭环、洗礼、升华、人生的真谛、生命的意义、在这一刻我顿悟了。
- 开头套话：光阴似箭日月如梭、时光如白驹过隙、记忆的长河、翻开记忆的相册、往事如烟。
- 网络语与热梗：yyds、绝绝子、破防、拿捏、栓 Q、emo、卷、躺平。
- 堆砌：连续三句以上排比、每段一个比喻、通篇四字短语、把成语当细节用。

**句子长度**：多数句子 15–30 字，穿插 5–10 字短句；出现超过 60 字的长句就拆开。

**判断口诀**：一句话如果可以在任何一篇作文里通用，就是废话，换成此刻此地才有的细节。

## 5. 开头与结尾

开头三选一：直接进场景（"哨声响的时候，我还在跑道的最后一个弯道。"）；一句短对话；一个具体物件。结尾三选一：回到开头的物件或场景；写出一个小小的变化；一句不加修饰的感受。避免"通过这件事我明白了一个道理……"这种硬贴标签，感悟要藏在动作或画面里。

## 6. 英语写作五步

1. 把题目里的提示问题 / 图片 / 表格逐条编号，形成信息点清单。
2. 判定主导时态（习惯→一般现在；last / yesterday→一般过去；plan / tomorrow / will→一般将来），全篇统一。
3. 一个信息点写一句，用 `and / but / because / so / then` 连接，句长控制在 8–16 词。
4. 补一句感受收尾；应用文补称呼与落款。
5. 逐句核对：三单 -s、时态、单复数、冠词、拼写、首字母大写、句末标点、是否出现真实姓名。

## 7. 成稿自检清单

语文：题目规范 / 字数达标 / 5–7 段且段首空两格 / 一件事写透 / 重点段有细节 / 有情感变化 / 结尾扣题 / 无真实校名师生姓名 / 无成人腔与网络语 / 无错别字与英文标点 / 标点使用正确。

英语：信息点全覆盖 / 句数与词数达标 / 时态统一 / 三单与单复数 / 拼写与大小写 / 句末标点 / 无真实姓名 / 无从句与超纲词 / 应用文格式完整。

## 8. 交付时附给孩子的思路说明

正文之后另起一段，写 3–5 条，每条一句话，说明：审题抓住了哪个题眼、选了什么事、详略怎么分、情感线怎么走、用了哪两处细节。再给 1–2 个引导问题，例如"这件事你有没有自己的版本？把第 4 段换成你真实遇到卡点的那一次"。目的是让孩子能改写，不是替孩子交作业。
