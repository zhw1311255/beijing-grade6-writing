# 语文习作 · 人教版（统编版）· 北京六年级考试口径

## 1. 教材版本与单元习作目录

语文教材为**人教版 / 统编版（部编版）**。北京各区语文考试卷面仍按本市六年级期末、毕业考要求执行——教材版本与考试区域是两件事，勿混。

**规则**：用户给出单元或题目原文时严格按用户给的习作要求执行；只说"单元作文"而未给题目时，按区级统考通用要求写，并在交付说明里注明所用假设。统编版不同修订年份的单元序号略有变动，不把单元号当成通用事实写进作文。

### 六年级上册单元习作（写作要素比题目本身更重要）

| 单元 | 习作 | 核心要素 |
| --- | --- | --- |
| 一 | 变形记 | 想象变成另一样事物后的经历，把重点部分写详细 |
| 二 | 多彩的活动 | 点面结合写场面，既写全场气氛又写个别人物 |
| 三 | ____让生活更美好 | 半命题补全，写清"为什么更美好"，把原因写具体 |
| 四 | 笔尖流出的故事 | 虚构故事，围绕主要人物展开，情节完整，有环境描写 |
| 五 | 围绕中心意思写 | 选一个字 / 词为中心，从不同方面或不同事例写，详略得当 |
| 六 | 学写倡议书 | 应用文：标题、称呼、正文、倡议内容、署名日期，理由充分 |
| 七 | 我的拿手好戏 | 写练成的过程与展示的场面，有细节、有波折 |
| 八 | 有你，真好 | 通过一件事写一个人，融入真情，写出"真好"的原因 |

## 2. 字数矩阵（关键，易错）

| 场景 | 常见要求 | 处理 |
| --- | --- | --- |
| 区级期末 / 毕业考试 | 不少于 400 字（昌平、海淀等）、不少于 450 字（朝阳 2025–2026 毕业考） | 默认写 450–480 字，稳妥覆盖两种口径 |
| 校内单元习作 / 老师另行规定 | 常见 500 字以上（旧京改版教材评价量表为 500 字以上，作口径旁证） | 写 520–560 字；统编版教材本身多不规定字数，以老师要求为准 |
| 课程标准 5–6 年级 | 40 分钟完成不少于 400 字的习作 | 下限参考 |
| 民间整理的"六年级 30 分制作文不少于 500 字" | 参考值，非卷面要求 | 以题目原文为准，不主动套用 |

**原则**：题目写了字数就严格照办（只多 10% 左右，超长同样会被认为详略不当）。没写就按上表场景取默认值。字数以**汉字数**为准，用 `scripts/check_writing.py` 统计，不靠估算。

## 3. 卷面硬约束（语文卷每套题基本都有）

1. 内容积极向上。
2. 把事情写具体，详略得当；表达真情实感，情感有变化要把变化写清楚。
3. **不得出现真实的学校名称、师生姓名**——用"我们学校""班主任""语文老师""同桌""小宇（化名）"替代。
4. 自拟题目时题目要贴题，命题作文题目照抄不改写，半命题补全后照抄完整题目。
5. 书写规范、行款整齐、正确使用标点、不写错别字。
6. 分段表述（5–7 段为宜），段落开头空两格。
7. 符合人教版对应单元的习作要素（点面结合、围绕中心意思写、写出情感变化、倡议书格式等）。

## 4. 常见题型（据北京近年真题）

- **二选一最常见**：题目一为命题记叙文（写人记事、成长感悟），题目二为想象文 / 科幻故事（自拟题目）。
- 命题、半命题（补题后照抄）、话题作文、材料作文。
- 想象文：未来星球、时光穿梭、假如记忆可移植、AI 伙伴等，要求"想象合理、情节具体生动"（与人教版六上"变形记"、六下"插上科学的翅膀飞"训练要素相通）。
- 读后感 / 观后感 / 作品梗概：引—议—联—结，感为主、事为铺垫；梗概只叙述不抒情。
- 应用文与实用写作：倡议书、书信、演讲稿、成长纪念册、好书推荐、文创设计说明。
- 综合性学习类：回忆小学生活、一次特别的作业、一项活动（点面结合写场面）。

真题样例：

| 来源 | 题目 | 要求 |
| --- | --- | --- |
| 朝阳 2025–2026 六下毕业考 | 成长里的温暖 / 3050 年未来星球故事 | 事情写具体、真情实感、不出现真实校名师生姓名、不少于 450 字 |
| 昌平 2025–2026 六下期末 | 成长 / 假如……科幻故事 | 叙述具体、详略得当、标点正确、不少于 400 字 |
| 东城 2023 小升初 | 一次____的作业 | 补题、写清过程、重点部分写具体、不少于 400 字 |
| 朝阳 2023 小升初 | 让真情自然流露（印象最深的一种感受） | 内容写具体、写清情感变化、自拟题目、不少于 400 字 |

## 5. 评分量表（用于成稿自检，不必向用户展示分数）

**海淀区六年级期末 40 分制**（内容表达 36 分 + 书写 4 分）：

| 等级 | 内容 | 结构 | 语言 |
| --- | --- | --- | --- |
| 一类 40–34 | 符合题意，选材适当，积极向上，内容具体 | 结构完整，条理清楚，能分段表述 | 语句通顺，感情真实，尝试运用平时积累的语言材料 |
| 二类 33–30 | 比较符合题意，内容比较具体 | 比较完整，条理比较清楚 | 比较通顺，能表达自己的感受 |
| 三类 29–24 | 基本符合题意，相关度不高 | 基本完整 | 基本通顺 |
| 四类 23–0 | 选材不符合题意，只写几行 | 不能成文 | 语言不成句 |

书写 4 分：整洁且错别字 5 个以内得 4 分；错别字较多影响表达递减。想象文一类另要求"自拟题目、想象有新意、重点部分描写详细"。

**单元习作评价量表旁证**（旧京改版第 12 册《我的苦与乐》，两维四级；仅用于理解校内量表关注点，不作选题依据）：结构篇幅看"结构完整 / 条理清楚 / 安排材料合理 / 500 字以上"；内容看"观点鲜明、感情真挚、事例生动具体（语言动作神态心理）、语言流畅用词准确"。

**启示**：得分点是"具体 + 真实 + 条理 + 语言干净"，不是辞藻。避免用华丽但空的句子换掉细节描写。

## 6. 北京本地素材库（同龄人可感，避免空泛）

- 校园：运动会八百米、朗诵活动、课本剧排练、值周、图书角、科学小实验、一次难题的破解、课间十分钟的操场、毕业前最后一次大扫除。
- 家庭：一顿家常饭、一次学骑车、和长辈逛早市、教爷爷奶奶用手机、一起修好一件旧物、雨中送伞。
- 北京本地：胡同里的叫卖声、中轴线徒步、国博 / 首博的一次参观、颐和园的十七孔桥、社区志愿服务、垃圾分类值守、庙会与春节习俗（对应六下"家乡的风俗"）、下雪后的胡同、地铁上的一次让座。
- 成长感受：第一次独立办成一件事、被误解后和解、坚持练一项技能、告别与感谢。

使用要求：选**一件小事**，写清时间地点人物、经过、卡点、转折、感受；本地元素只作背景，不写成导游词或文化散文。

## 7. Word 与 PDF 排版规格（语文）

- A4，页边距上下 2.54 cm、左右 3.17 cm（Word 默认）。
- 题目：居中，宋体或黑体加粗，三号（16 pt），段后空一行。
- 正文：宋体小四（12 pt），**首行缩进 2 字符**，1.5 倍行距，段前段后 0。
- 段落之间不空行；对话独立成段时同样缩进。
- 文末右对齐附"（全文 XXX 字）"，该行不属于作文正文，便于核对字数。
- `scripts/make_docx.py --lang zh` 与 `scripts/make_pdf.py --lang zh` 均按上述参数实现；统一入口 `scripts/make_outputs.py --format docx|pdf|both`，默认只出 docx，按用户需要选一种，只有明确要求双格式时才用 both。
- PDF 实现：`make_pdf.py` 生成带 `@page { size: A4; margin: 2.54cm 3.17cm; }` 的 HTML，正文 `font-family: SimSun`、`text-indent: 2em`、`line-height: 1.5`，交给本机 Edge / Chrome 无头打印。中文由系统字体直接渲染，无需安装 PDF 库或字体包，且文字可复制、可检索。
